Detailed Description

Abstract class which receives the parsed Midi events.

Subclass it and implement at least onNoteOn(), onNoteOff(), onControlChange() and onPitchBend(). The other events have an empty default implementation which you can override when needed. Channels are 0..15, all other values 0..127 unless noted otherwise. Note On messages with a velocity of 0 are reported as onNoteOff().

by Phil Schatzmann
