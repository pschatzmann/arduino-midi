Detailed Description

A streaming Midi Parser which calls the corresponding events. It supports Midi byte streams (with running status) via parse() and BLE Midi packets via parseBle(). The parser keeps its state between calls, so messages can be split over multiple calls.

Supported channel voice messages: note on/off, poly pressure, control change, program change, channel pressure and 14 bit pitch bend. They are forwarded to the MidiAction. System exclusive, system common and system realtime messages are skipped (realtime messages may also appear in the middle of another message).

If you indicate the channel (0..15) in the constructor or in begin(), it is used as filter to process only the messages for the indicated channel. You can subclass the parser and override the on...() methods to intercept the events.
